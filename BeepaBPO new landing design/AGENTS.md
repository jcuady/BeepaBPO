## Application rules
- Keep the Beepa marketing journey on the index route with in-page section navigation, because this is a single editorial landing page.
- Use the shared CSS design system and Button variants for branded controls, because branding must remain consistent throughout the buyer journey.
- Treat the team planner and career brief as browser-only downloadable drafts, never as submitted inquiries, until a real contact destination is supplied.
- Import generated photography as project assets and uploaded branding through asset pointers, because source branding must be preserved without storing uploaded binaries.
