## How to use this

This is the bounded surface for a per-page functional review. For each row:

1. Sign in as a role that can reach the route and confirm it renders.
2. Confirm the gate column matches what the role should be allowed to do.
3. Exercise every control on the page and confirm it reaches a real workflow.
4. Confirm the server action it calls is itself authorized in `lib/**/actions.ts`.

`scripts/audit/audit-page-wiring.mjs` covers step 3 statically (dead buttons,
unsubmittable forms, links to missing routes) and currently reports zero candidates.
`scripts/audit/audit-rbac.mjs` and `audit-action-rbac.mjs` cover steps 2 and 4.
